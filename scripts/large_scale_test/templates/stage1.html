Julia compatibility

  

    We follow each package's declared Julia compat (its Compat.toml). No
    guessing whether older-declared packages would secretly work on 1.12.

    Lower-bound range = the lowest Julia version the package
    declares support for. e.g. 1.9 means "developed against
    Julia ≥ 1.9." Higher = more recent code, but may use newer Julia
    features. Format: major.minor, e.g. 1.10.
  

  

    
    
    
  


  
Numeric thresholds

  

    rdeps = packages that depend on this one. Counterintuitive:
    low rdeps (newbie / experimental code) tends to use simpler Julia and may
    be the easier set for a static checker. High rdeps (StaticArrays
    etc.) often means heavy metaprogramming and type piracy. Defaults leave
    rdeps unfiltered.

    n_deps = direct dep count. Low = simple leaf utility.
